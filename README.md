# DollarReader

DollarReader — локальная Android-читалка для ранобэ, книг и документов с библиотекой по тайтлам, томам и главам.

## Цели проекта

- Android 10+ (`minSdk 29`).
- Быстрый и аккуратный интерфейс для бюджетных устройств, включая Redmi 9.
- Импорт локальных книг и архивов с отдельными главами.
- EPUB, FB2, PDF, TXT, HTML и другие форматы по мере развития.
- Выделения, заметки, закладки, словарь, Google Search и Google Translate.
- Опциональная синхронизация прогресса через Google Drive.
- Источники RanobeHub и RanobeLib как изолированные модули.

## Рабочий процесс

Разработка ведётся прямо в `main`. Каждый законченный этап должен оставлять `main` собираемым и пригодным для установки. Начиная с ветки версий `0.3.x`, функции объединяются в крупные законченные пакеты вместо мелких выпусков на одну кнопку.

## Текущий этап

`0.3.0-alpha02` — крупный пакет структурированных книг и сохранности данных.

DollarReader импортирует EPUB, HTML и XHTML через системный Android-проводник. Для EPUB читаются метаданные, манифест и порядок глав из spine; локальные стили, шрифты и иллюстрации сохраняются рядом с текстом. HTML может импортироваться как один документ или как несколько глав по тегам `<article>`. Перед записью показываются оглавление и изменения относительно ранее импортированной версии.

Для EPUB и HTML используется отдельная локальная читалка, которая сохраняет оформление документа, иллюстрации и относительные ресурсы, но блокирует сетевые запросы и активный внешний контент. Темы, размер текста, поля, ширина и интервалы DollarReader применяются поверх оформления книги. Позиция чтения и переходы между главами сохраняются так же, как для TXT.

Поисковый FTS-индекс извлекает обычный текст из HTML-глав, поэтому структурированные книги участвуют в общем поиске. В настройках появились экспорт заметок, подсветок и закладок в Markdown, а также переносимый ZIP-архив с Room-базой и внутренними копиями библиотеки. Встроенное восстановление из архива будет отдельным этапом.

Следующий крупный этап — восстановление резервных копий, импорт FB2 и улучшенная работа с изображениями, оглавлением и метаданными EPUB.
