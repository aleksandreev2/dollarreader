# DollarReader

DollarReader — локальная Android-читалка для ранобэ, книг и документов с библиотекой по тайтлам, томам и главам.

## Цели проекта

- Android 10+ (`minSdk 29`).
- Быстрый и аккуратный интерфейс для бюджетных устройств, включая Redmi 9.
- Импорт локальных книг и архивов с отдельными главами.
- EPUB, FB2, PDF, TXT, HTML и другие форматы по мере развития.
- Выделения, заметки, закладки, словарь, Google Search и Google Translate.
- Опциональная синхронизация прогресса через Google Drive.
- Источники RanobeHub и RanobeLib как изолированные модули.

## Рабочий процесс

Разработка ведётся прямо в `main`. Каждый законченный этап должен оставлять `main` собираемым и пригодным для установки. Начиная с ветки версий `0.3.x`, функции объединяются в крупные законченные пакеты вместо мелких выпусков на одну кнопку.

## Текущий этап

`0.3.0-alpha03` — восстановление резервных копий и расширение структурированной библиотеки.

Добавлен безопасный мастер восстановления: архив сначала проверяется, затем распаковывается во внутренний временный каталог и применяется только при следующем создании главного экрана до открытия Room. При ошибке файловой операции прежняя база и библиотека возвращаются из локального отката.

DollarReader теперь импортирует FB2, преобразует разделы в локальные HTML-главы, сохраняет встроенные изображения и открывает книгу в богатой читалке. Несколько `body` и крупные вложенные разделы превращаются в отдельные тома или части.

EPUB-импорт учитывает навигационный документ EPUB 3 и NCX: названия глав берутся из штатного оглавления, а верхние уровни вложенной навигации становятся томами. Обложки и другие локальные иллюстрации отображаются в библиотеке без сетевых запросов.

Следующий крупный этап — мастер выборочного восстановления, импорт FB2.ZIP и PDF/CBZ с отдельными режимами чтения.

Подробный план находится в [`docs/ROADMAP.md`](docs/ROADMAP.md).
