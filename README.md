# DollarReader

DollarReader — локальная Android-читалка для ранобэ, книг и документов с библиотекой по тайтлам, томам и главам.

## Цели проекта

- Android 10+ (`minSdk 29`).
- Быстрый и аккуратный интерфейс для бюджетных устройств, включая Redmi 9.
- Импорт локальных книг и архивов с отдельными главами.
- EPUB, FB2, PDF, TXT, HTML и другие форматы по мере развития.
- Выделения, заметки, словарь, Google Search и Google Translate.
- Опциональная синхронизация прогресса через Google Drive.
- Источники RanobeHub и RanobeLib как изолированные модули.

## Рабочий процесс

Разработка ведётся прямо в `main`. Незавершённые эксперименты и бесполезные ветки не создаются. Каждый отправленный этап должен оставлять `main` собираемым и пригодным для установки.

## Текущий этап

`0.2.0-alpha07` — на странице тайтла можно редактировать название, автора и описание, управлять избранным, безопасно удалять локальную запись и просматривать историю импортов, обновлений и правок метаданных. Пользовательские данные не сбрасываются при последующем обновлении ZIP или папки. Следующая часть этапа — полноценные настройки чтения и сохранение позиции внутри главы.
