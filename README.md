# DollarReader

DollarReader — локальная Android-читалка для ранобэ, книг и документов с библиотекой по тайтлам, томам и главам.

## Цели проекта

- Android 10+ (`minSdk 29`).
- Быстрый и аккуратный интерфейс для бюджетных устройств, включая Redmi 9.
- Импорт локальных книг и архивов с отдельными главами.
- EPUB, FB2, PDF, TXT, HTML и другие форматы по мере развития.
- Выделения, заметки, закладки, словарь, Google Search и Google Translate.
- Опциональная синхронизация прогресса через Google Drive.
- Источники RanobeHub и RanobeLib как изолированные модули.

## Рабочий процесс

Разработка ведётся прямо в `main`. Каждый законченный этап должен оставлять `main` собираемым и пригодным для установки. Начиная с ветки версий `0.3.x`, функции объединяются в крупные законченные пакеты вместо мелких выпусков на одну кнопку.

## Текущий этап

`0.3.0-alpha04` — переработанное управление читалкой после проверки на физическом устройстве.

Кнопка увеличения громкости открывает предыдущую главу, кнопка уменьшения громкости — следующую. Горизонтальные свайпы между главами отключены, чтобы не конфликтовать с выделением текста и обычной прокруткой.

Верхняя и нижняя панели автоматически скрываются при прокрутке вниз и появляются при прокрутке вверх. В настройках чтения их можно закрепить на экране постоянно.

Для EPUB, HTML и FB2 отключено принудительное затемнение WebView, а цвета текста и фона явно задаются темой DollarReader. Это исправляет нечитаемый текст при одновременном включении тёмной темы приложения и ночной или чёрной темы читалки.

Room-база обновлена до версии 6 безопасной миграцией, которая сохраняет существующую библиотеку и добавляет настройку закрепления панелей.

Следующий крупный этап — мастер выборочного восстановления, импорт FB2.ZIP и PDF/CBZ с отдельными режимами чтения.
