# DollarReader

DollarReader — локальная Android-читалка для ранобэ, книг и документов с библиотекой по тайтлам, томам и главам.

## Цели проекта

- Android 10+ (`minSdk 29`).
- Быстрый и аккуратный интерфейс для бюджетных устройств, включая Redmi 9.
- Импорт локальных книг и архивов с отдельными главами.
- EPUB, FB2, PDF, TXT, HTML и другие форматы по мере развития.
- Выделения, заметки, закладки, словарь, Google Search и Google Translate.
- Опциональная синхронизация прогресса через Google Drive.
- Источники RanobeHub и RanobeLib как изолированные модули.

## Рабочий процесс

Разработка ведётся прямо в `main`. Каждый законченный этап должен оставлять `main` собираемым и пригодным для установки. Начиная с ветки версий `0.3.x`, функции объединяются в крупные законченные пакеты вместо мелких выпусков на одну кнопку.

## Текущий этап

`0.3.0-alpha01` — крупное обновление рабочего пространства чтения. Добавлены настоящие закладки текущей позиции, редактирование заметок и названий закладок, множественный выбор и удаление меток. Поиск больше не перечитывает всю библиотеку при каждом запросе: абзацы локальных TXT-глав хранятся в постоянном Room FTS4-индексе, который обновляется только для новых и изменённых глав.

Раздел «Метки» теперь объединяет закладки, заметки, подсветки, избранные тайтлы, состояние поискового индекса и ручное безопасное перестроение индекса.

Следующий крупный этап — импорт и полноценное чтение EPUB/HTML, экспорт заметок и резервное копирование пользовательских данных.

Подробный план находится в [`docs/ROADMAP.md`](docs/ROADMAP.md).
