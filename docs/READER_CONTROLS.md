# Управление читалкой

## Физические кнопки

Во время чтения DollarReader перехватывает кнопки громкости:

- `Громкость +` — предыдущая глава;
- `Громкость −` — следующая глава.

Один физический нажим выполняет один переход. Удержание кнопки не перелистывает сразу несколько глав. Вне экрана чтения кнопки снова управляют системной громкостью.

## Панели

По умолчанию верхняя панель и нижняя карточка прогресса:

- скрываются при прокрутке вниз;
- появляются при прокрутке вверх;
- всегда показываются возле начала главы;
- остаются видимыми во время работы с выделенным текстом.

Переключатель `Закрепить панели читалки` находится в настройках чтения. После закрепления панели больше не скрываются.

## Цветовые темы

TXT-читалка использует отдельные контрастные цвета текста, заметок и подсветок для каждой темы.

EPUB, HTML и FB2 открываются в локальной WebView. Системное автоматическое затемнение WebView отключено, поскольку цветами управляет DollarReader. Вложенные стили книги не могут оставить чёрный текст на чёрном фоне: основной текст, заголовки, таблицы и ссылки получают контрастные цвета выбранной темы.
