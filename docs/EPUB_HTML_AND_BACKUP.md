# EPUB, HTML и резервные копии

## Импорт структурированных книг

DollarReader принимает EPUB, HTML, HTM и XHTML через системный Android-проводник. Приложение запрашивает только доступ к выбранному документу и пытается сохранить долгосрочное разрешение чтения для последующей проверки обновлений.

### EPUB

Импорт EPUB выполняется без распаковки во внешнее хранилище. Приложение:

1. проверяет `META-INF/container.xml`;
2. находит OPF-пакет;
3. читает название и автора из метаданных;
4. собирает манифест ресурсов;
5. использует `spine` как основной порядок глав;
6. сохраняет XHTML-главы, локальные CSS, изображения и шрифты во внутреннее хранилище;
7. создаёт оглавление DollarReader и стабильные идентификаторы глав.

Для защиты от повреждённых и намеренно опасных архивов ограничены количество записей, размер одного файла и суммарный распакованный объём. Пути с выходом за каталог книги отклоняются.

### HTML и XHTML

Обычный HTML импортируется как один документ. Когда в файле обнаружено несколько тегов `<article>`, каждый из них становится отдельной главой, а общий `<head>` используется для сохранения оформления.

Активное содержимое удаляется: скрипты, iframe, формы, обработчики событий и `javascript:`-ссылки. В импортированный документ добавляется локальная Content Security Policy.

## Богатая читалка

EPUB и HTML открываются в отдельной локальной WebView-читалке. Сетевые загрузки заблокированы, JavaScript используется только для применения локальных настроек DollarReader. Относительные ссылки на изображения, стили и шрифты продолжают работать внутри внутреннего каталога книги.

Поверх оформления документа применяются:

- выбранная тема;
- гарнитура и размер текста;
- межстрочный интервал;
- расстояние между абзацами;
- красная строка;
- ширина текста и боковые поля.

Для каждой главы сохраняются точное вертикальное смещение и процент прохождения. Кнопки предыдущей и следующей главы используют тот же механизм прогресса, что и TXT-читалка.

## Поиск

Перед добавлением главы в Room FTS4 HTML преобразуется в обычный текст. Благодаря этому EPUB и HTML участвуют в общем поиске по библиотеке, а в результатах не отображаются теги и CSS.

## Экспорт заметок

Экспорт Markdown включает:

- название тайтла и главы;
- номер абзаца;
- текст подсветки;
- текст заметки;
- название закладки.

Файл создаётся в выбранном пользователем месте через Storage Access Framework.

## Переносимая резервная копия

ZIP-архив содержит:

- `backup-info.json` с версией формата и краткой статистикой;
- Markdown-экспорт сохранённого;
- Room-базу и её служебные файлы после WAL checkpoint;
- внутренний каталог библиотеки с TXT, HTML, XHTML, CSS, шрифтами и иллюстрациями.

Исходные документы пользователя в архив не копируются: сохраняется только внутренняя рабочая библиотека DollarReader. Встроенное восстановление из такого архива пока не реализовано; архив предназначен для сохранности данных и будущего мастера восстановления.

## Удаление

После удаления тайтла приложение удаляет весь его внутренний каталог, включая вложенные изображения, стили и шрифты. Выбранный пользователем исходный EPUB, HTML, TXT, ZIP или каталог не изменяется.
