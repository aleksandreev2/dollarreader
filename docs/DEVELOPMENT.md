# Разработка

## Правило веток

Работа ведётся напрямую в `main`. Ветки и pull request не создаются без отдельной причины и явного согласования.

## Требования

- Android Studio с JDK 17.
- Android SDK 36.
- Устройство или эмулятор с Android 10 и новее.

## Открытие проекта

1. Клонировать репозиторий.
2. Открыть корневую папку `dollarreader` в Android Studio.
3. Дождаться Gradle Sync.
4. Выбрать устройство и нажать Run.

Gradle Wrapper добавляется автоматически первым запуском GitHub Actions.

## Проверка перед отправкой

```bash
./gradlew :app:assembleDebug
./gradlew :app:lintDebug
```

## Целевое устройство

Основной профиль производительности — Redmi 9, Android 10. Тяжёлые размытия и непрерывные декоративные анимации не используются.
